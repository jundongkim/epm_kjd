# IoT Algorithm: AutoML 파이프라인 제품 요구사항 명세서 (PRD)

## 1. 개요 (Overview)

### 1.1. 프로젝트 정의
**IoT Algorithm**은 IoT 시계열 데이터를 위한 자동화된 머신러닝(AutoML) 파이프라인 도구입니다. 복잡한 데이터 전처리, 피처 엔지니어링, 모델 학습 및 평가 과정을 자동화하고, 사용자가 코딩 없이도 쉽고 빠르게 최적의 ML 모델을 구축하고 비교할 수 있도록 지원합니다.

### 1.2. 해결하려는 문제
IoT 데이터를 활용해 ML 모델(예: 고장 예측, 수율 예측)을 개발하는 과정은 데이터 정제, 피처 추출, 모델 선택, 하이퍼파라미터 튜닝 등 많은 시간과 전문 지식을 요구하는 복잡한 작업입니다. 현장 엔지니어나 분석가는 이 과정의 복잡성 때문에 데이터 기반의 예측 모델을 구축하는 데 어려움을 겪습니다. `IoT Algorithm`은 이 전체 워크플로우를 체계적이고 자동화된 UI로 제공하여, 누구나 신속하게 고성능 ML 모델을 개발할 수 있도록 합니다.

---

## 2. 목표 (Goals)

*   **ML 파이프라인 자동화**: 데이터 로드부터 모델 평가까지, 전체 ML 워크플로우를 자동화하여 모델 개발에 드는 시간과 노력을 획기적으로 줄입니다.
*   **신속한 모델 비교 및 선택**: 다양한 알고리즘을 동일한 조건에서 학습시키고, 성능을 직관적으로 비교하여 최적의 모델을 신속하게 선택할 수 있도록 지원합니다.
*   **비전문가의 ML 접근성 향상**: 복잡한 코딩이나 ML 이론에 대한 깊은 이해 없이도, 현장 전문가가 자신의 도메인 지식을 활용하여 직접 예측 모델을 구축할 수 있도록 합니다.
*   **프로세스 표준화**: 데이터 처리 및 모델링 과정을 표준화하여, 분석 결과의 일관성과 재현성을 보장합니다.

---

## 3. 타겟 사용자 (Target Audience)

*   **제조 현장 엔지니어**: 설비 데이터를 기반으로 고장 예측, 품질 관리 등 예측 모델을 직접 구축하고 싶어하는 엔지니어.
*   **데이터 분석가**: 반복적인 전처리 및 모델링 작업을 자동화하여, 피처 엔지니어링과 모델 성능 해석에 더 집중하고 싶은 분석 전문가.
*   **시티즌 데이터 사이언티스트**: ML 전문가는 아니지만, 현업 문제 해결을 위해 데이터 분석 및 모델링을 수행하고자 하는 실무 담당자.

---

## 4. 주요 기능 (Features)

### 4.1. 데이터 준비 파이프라인 (Data Prep Pipeline)
*   **데이터 로딩**: 다양한 포맷의 시계열 데이터 파일(CSV, Excel 등)을 업로드합니다.
*   **데이터 전처리 (Preprocessing)**:
    *   결측치 처리 (제거, 보간 등)
    *   이상치 탐지 및 처리
    *   데이터 타입 자동 감지 및 변환
*   **피처 엔지니어링 (Feature Engineering)**:
    *   시계열 피처 생성: Lag, 이동 평균/표준편차 등 통계 피처 자동 생성
    *   주파수 도메인 피처 생성 (FFT 등)
*   **피처 선택 (Feature Selection)**:
    *   모델 기반 중요도(SHAP, Permutation Importance)를 계산하여 핵심 피처를 자동 선택
    *   사용자가 직접 피처를 선택하거나 제외할 수 있는 기능
*   **데이터 정규화 (Normalization)**:
    *   StandardScaler, MinMaxScaler 등 모델에 적합한 스케일링 기법을 선택하여 적용합니다.

### 4.2. 자동화된 모델링 (Automated Modeling)
*   **다중 모델 동시 학습**: 분류(Classification) 및 회귀(Regression) 문제에 대해 여러 ML 알고리즘(예: CatBoost, LightGBM, RandomForest, XGBoost)을 동시에 학습시킵니다.
*   **자동 하이퍼파라미터 튜닝**: 각 모델에 대해 최적의 하이퍼파라미터를 자동으로 탐색하고 적용합니다.
*   **명확한 학습/검증 프로세스**: 데이터를 학습, 검증, 테스트 세트로 자동 분할하고 교차 검증(Cross-Validation)을 수행하여 모델의 일반화 성능을 확보합니다.

### 4.3. 모델 성능 비교 및 분석 (Model Comparison & Analysis)
*   **통합 성능 대시보드**: 모든 학습된 모델의 성능을 하나의 대시보드에서 비교합니다.
    *   **평가 지표**: 정확도, 정밀도, 재현율, F1-Score, ROC-AUC (분류) / MSE, RMSE, MAE, R² (회귀) 등 핵심 지표를 제공합니다.
    *   **시각화**: 혼동 행렬(Confusion Matrix), ROC 커브, 피처 중요도(Feature Importance) 등을 시각적으로 비교합니다.
*   **리더보드**: 가장 성능이 우수한 모델 순위를 보여주는 리더보드를 제공하여 최적 모델을 쉽게 식별할 수 있습니다.
*   **결과 저장 및 내보내기**: 학습된 모델과 평가 결과를 저장하고, 분석 리포트를 내보낼 수 있습니다.

### 4.4. 사용자 인터페이스 (UI) 및 워크플로우
*   **가이드 기반 워크플로우**: '데이터 로드' → '전처리/피처 선택' → '모델 학습' → '성능 비교' 단계로 이어지는 직관적인 UI를 제공합니다.
*   **실시간 피드백**: 각 파이프라인 단계의 처리 결과(예: 전처리 후 데이터 샘플, 생성된 피처 목록)를 즉시 확인하고 다음 단계를 결정할 수 있습니다.
*   **설정 유연성**: 각 단계의 세부 파라미터(예: 결측치 처리 방식, 사용할 모델)를 사용자가 직접 설정할 수 있는 고급 옵션을 제공합니다.

## 6. 성공 지표 (Success Metrics)

*   **모델 개발 시간 단축**: 전통적인 방식 대비, `IoT Algorithm`을 사용하여 목표 성능의 모델을 개발하는 데 걸리는 시간.
*   **사용자 채택률**: ML 비전문가인 현장 엔지니어의 월간 활성 사용자 수(MAU).
*   **파이프라인 실행 성공률**: 사용자가 '데이터 로드'부터 '모델 평가'까지 전체 파이프라인을 중단 없이 완료하는 비율.
*   **모델 성능**: 생성된 모델이 사전에 정의된 성능 목표(예: 예측 정확도 95%)를 달성하는 비율.
