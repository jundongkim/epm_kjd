# IoT Data Analyzer - 모듈화된 구조

이 디렉토리는 IoT 데이터 생성 및 분석 도구의 모듈화된 구조입니다. 원래의 단일 파일(`iot_data_analyzer.py`)에서 아래와 같이 기능별로 분리되었습니다.

## 디렉토리 구조

```
iot/
├── __init__.py           # 패키지 초기화
├── utils/                # 유틸리티 함수 패키지
│   ├── __init__.py       # 유틸리티 초기화
│   ├── data_utils.py     # 데이터 관리 및 I/O 유틸리티
│   ├── processing_utils.py # 데이터 처리 및 변환 유틸리티
│   ├── analysis_utils.py # 분석 및 계산 유틸리티
│   ├── generator_utils.py # 데이터 생성 알고리즘
│   ├── style.py          # UI 스타일 및 폰트 관련 함수
│   ├── ai_settings.py    # AI 관련 설정 함수
│   └── ai_utils.py       # AI 분석 유틸리티
├── main.py               # 애플리케이션 메인 진입점
├── iot_data/             # 생성된 CSV 파일 저장 디렉토리
│   └── *.csv             # 생성된 데이터 파일들
└── visualizations/       # 시각화 모듈 패키지
    ├── __init__.py       # 시각화 모듈 초기화
    ├── timeseries.py     # 시계열 차트 모듈
    ├── histogram.py      # 히스토그램 모듈
    ├── boxplot.py        # 박스플롯 모듈
    ├── heatmap.py        # 히트맵 모듈
    ├── pattern.py        # 일별/시간별 패턴 분석 모듈
    ├── anomaly.py        # 이상치 분석 모듈
    ├── fft.py            # 주파수 분석(FFT) 모듈
    ├── timefreq.py       # 시간-주파수 분석 모듈
    ├── trend.py          # 트렌드 분석 모듈
    ├── correlation.py    # 상관관계 분석 모듈
    ├── threed.py         # 3D 데이터 시각화 모듈
    ├── distribution.py   # 분포 비교 모듈
    ├── clustering.py     # 패턴 클러스터링 모듈
    ├── alarm_threshold.py # 경보 및 임계값 설정 모듈
    ├── visualization_guide.py # 시각화 가이드 모듈
    ├── guide_data.py     # 시각화 가이드 데이터 모듈
    ├── guide_ui.py       # 시각화 가이드 UI 컴포넌트
    └── guide_ai.py       # 시각화 가이드 AI 분석 모듈
```

## 모듈 설명

1. **utils/**: 기본 유틸리티 함수를 포함하는 패키지입니다.
   - **data_utils.py**: 데이터 관리, 파일 저장 및 다운로드 관련 함수
   - **processing_utils.py**: 데이터 처리 및 변환 유틸리티
   - **analysis_utils.py**: 데이터 분석 및 계산 함수 (FFT, 상관관계 등)
   - **generator_utils.py**: IoT 데이터 생성 알고리즘 및 다양한 패턴 생성 함수
   - **style.py**: UI 스타일 및 폰트 관련 함수
   - **ai_settings.py**: AI 분석 관련 설정 함수
   - **ai_utils.py**: AI 기반 분석 및 추론 기능
   
2. **visualizations/**: 다양한 시각화 모듈을 포함하는 패키지입니다.
   - **timeseries.py**: 시계열 데이터 시각화 및 분석
   - **histogram.py**: 분포 히스토그램 및 관련 통계
   - **boxplot.py**: 박스플롯 및 그룹별 통계 분석
   - **heatmap.py**: 시간별/월별 히트맵 분석
   - **pattern.py**: 일별/시간별 패턴 분석
   - **anomaly.py**: 이상치 감지 및 분석
   - **fft.py**: 주파수 영역 분석(FFT)
   - **timefreq.py**: 웨이블릿 변환을 통한 시간-주파수 분석
   - **trend.py**: 추세 분석(이동평균, 계절성 분해 등)
   - **correlation.py**: 상관관계 분석 및 시각화
   - **threed.py**: 3D 데이터 시각화
   - **distribution.py**: 여러 분포 비교 및 시각화
   - **clustering.py**: 시계열 패턴 클러스터링 및 분석
   - **alarm_threshold.py**: 경보 및 임계값 설정 분석
   - **visualization_guide.py**: 데이터 특성에 기반한 시각화 추천 시스템

3. **시각화 가이드 모듈**: 더 효과적인 데이터 분석을 위한 인터랙티브 가이드 시스템
   - **guide_data.py**: 분석 추천 데이터 및 데이터 특성 분석 로직
   - **guide_ui.py**: 가이드용 UI 컴포넌트 및 흐름도 렌더링
   - **guide_ai.py**: 가이드를 위한 AI 분석 모듈

4. **main.py**: 메인 애플리케이션 코드를 포함합니다.
   - Streamlit 앱의 메인 진입점
   - 모듈 통합 및 UI 구성
   - 세션 상태 관리 및 페이지 간 네비게이션 제어

## 새로운 기능

### 시각화 가이드 시스템

최근 추가된 "시각화 가이드" 시스템은 데이터 특성을 자동으로 분석하여 최적의 분석 경로를 추천합니다:
- 데이터의 시계열 특성, 분포, 이상치, 주기성 등을 자동 감지
- 분석 목적별 최적의 시각화 방법 추천
- 클릭 가능한 인터랙티브 버튼으로 바로 해당 시각화 메뉴로 이동
- 분석 흐름도를 통한 데이터 탐색 경로 시각화
- 데이터 특성에 기반한 분석 인사이트 제공

### 향상된 페이지 네비게이션

세션 상태 관리 기능이 강화되어 사용자 경험이 개선되었습니다:
- 버튼 클릭을 통한 페이지 간 이동 시 상태 유지
- URL 파라미터를 통한 직접 시각화 페이지 접근 지원
- 사용자가 선택한 설정이 페이지 이동 후에도 유지
- 세션 기반 상태 저장으로 분석 연속성 보장

### 운전/정지 주기 패턴

"운전/정지 주기" 패턴은 산업 장비의 가동 및 정지 사이클을 시뮬레이션합니다:
- 설정 가능한 운전 및 정지 시간 (분 단위)
- 부드러운 전환 구간 (램프 업/다운)을 통한 현실적인 데이터 생성
- 운전 중에는 높은 센서값, 정지 중에는 낮은 센서값 유지
- 다양한 산업 설비(배치 프로세스, 냉각 시스템, 주기적 가동 장비 등)의 패턴 구현 가능

### 대용량 데이터 처리 개선

메모리 관리 옵션이 추가되어 대용량 데이터셋 처리 성능이 향상되었습니다:
- 샘플링 기반 메모리 사용량 최적화
- 사용자 지정 최대 메모리 포인트 설정 기능
- 대용량 파일 처리 시 자동 샘플링 및 알림
- 원본 데이터는 CSV로 보존하면서 시각화용 데이터는 최적화

### 시간-주파수 분석

시간-주파수 분석 모듈은 웨이블릿 변환을 사용하여 신호의 시간적, 주파수적 특성을 동시에 분석합니다:
- 다양한 웨이블릿 타입(Morlet, Complex Morlet, Gaussian derivative, Mexican hat) 지원
- 시간에 따른 주파수 변화를 히트맵으로 시각화
- 주파수 대역별 에너지 분포 분석
- 특정 시간대의 주기적 패턴 식별
- 비정상 주파수 패턴 및 일시적 이벤트 감지

### AI 분석 기능

시각화 모듈에 AI 분석 기능이 통합되었습니다:
- 히스토그램, 박스플롯 등의 데이터에 대한 자동 분석 제공
- 데이터에 대한 질문-응답 인터페이스 지원
- 복잡한 패턴과 통계적 특성에 대한 인사이트 제공
- 데이터 특성에 맞는 예방 정비 및 최적화 제안 생성

## 향후 추가 고려 분석 대상

### 예측 분석 시각화 (Forecasting)
- 시계열 예측 모델(ARIMA, Prophet, LSTM 등)을 통합하여 미래 데이터 트렌드 예측
- 예측 신뢰 구간과 함께 과거 데이터와 미래 예측을 한 차트에 표시
- 다양한 예측 기간(1일, 1주, 1개월 등) 선택 옵션

### 이상치 원인 분석 (Anomaly Root Cause Analysis)
- 현재 이상치 감지는 있지만, 이상치 발생 시 연관 변수나 조건의 상관관계 분석 추가
- 이상치 발생 전후의 다른 센서 데이터 변화를 시각화
- Sankey 다이어그램으로 이상치 발생 경로 및 영향 분석

### 멀티센서 간 관계 분석
- 여러 센서 데이터 간의 복잡한 관계를 네트워크 그래프로 시각화
- 인과관계 분석(Granger Causality)을 통한 선행-후행 관계 파악
- 센서 간 관계 변화의 시간적 추이 시각화

### 기기 수명주기 분석
- 장비 상태 변화와 노화 패턴을 장기간에 걸쳐 시각화
- 상태 지표의 점진적 변화를 감지하여 유지보수 시점 예측
- 다른 유사 장비와의 상태 비교 벤치마킹

### 워터폴/캐스케이드 차트
- 시간에 따른 값의 변화 요인을 분해하여 시각화
- 특정 지표의 변화에 기여하는 다양한 요소들의 상대적 기여도 분석
- 시간대별 또는 운영 모드별 성능 변화 원인 분석

# IoT Prism

제조 설비 IoT 데이터를 시각화하고 분석하는 프로젝트입니다.

## 주요 기능

- 다양한 IoT 데이터 시각화 (시계열, 히스토그램, 히트맵 등)
- 설비 성능 및 이상 분석
- 패턴 및 추세 분석
- 종합 인사이트 리포트 생성
- IoT 데이터 기반 예측 및 권장사항
- 사용자 친화적 인터페이스

## 인사이트 모듈 (IoT_Prism)

IoT Prism은 설비 데이터에 대한 종합 인사이트를 자동으로 생성합니다. 이 모듈은 다음과 같은 핵심 기능을 제공합니다:

1. **종합 인사이트 리포트**: 현재 로드된 데이터를 기반으로 심층 분석 리포트를 생성합니다.
2. **시각화 기록**: 사용자가 활용한 모든 시각화 기록을 자동으로 수집하고 표시합니다.
3. **질문 및 답변**: 데이터에 대한 질문을 입력하면 자동으로 답변을 생성합니다.

### 인사이트 리포트 유형

- **종합 분석 리포트**: 데이터의 전반적인 특성, 통계, 추세, 이상치 등을 포괄적으로 분석
- **이상치 분석 리포트**: 데이터 내 이상치에 초점을 맞춘 심층 분석
- **패턴 분석 리포트**: 시간별, 일별, 요일별 패턴을 분석
- **성능 추세 리포트**: 설비 성능의 장기적 추세에 대한 분석

### 사용 방법

1. 데이터를 로드하거나 생성합니다.
2. 시각화 옵션에서 "종합 인사이트"를 선택합니다.
3. 원하는 리포트 유형과 분석 옵션을 선택합니다.
4. "인사이트 생성" 버튼을 클릭하여 리포트를 생성합니다.
5. 생성된 리포트는 마크다운 형식으로 다운로드할 수 있습니다.
