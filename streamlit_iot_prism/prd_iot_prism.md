# IoT Prism 제품 요구사항 명세서 (PRD)

## 1. 개요 (Overview)

### 1.1. 프로젝트 정의
**IoT Prism**은 제조 및 산업 현장에서 발생하는 대규모 IoT(사물인터넷) 센서 데이터를 직관적으로 시각화하고, AI 기반으로 심층 분석하여 설비의 상태와 성능에 대한 종합적인 인사이트를 제공하는 웹 기반 분석 도구입니다.

### 1.2. 해결하려는 문제
제조 현장의 엔지니어와 데이터 분석가는 방대한 양의 시계열 데이터를 다루지만, 데이터의 복잡성으로 인해 의미 있는 정보를 신속하게 파악하기 어렵습니다. 데이터에서 이상 징후를 조기에 발견하거나, 설비의 성능 저하 원인을 분석하고, 유지보수 시점을 예측하는 데 많은 시간과 전문 지식이 필요합니다. IoT Prism은 이러한 과정을 자동화하고 단순화하여 사용자가 데이터에 기반한 빠르고 정확한 의사결정을 내릴 수 있도록 지원합니다.

---

## 2. 목표 (Goals)

*   **직관적인 데이터 탐색**: 사용자가 코딩이나 복잡한 통계 지식 없이도 다양한 관점에서 데이터를 시각화하고 탐색할 수 있는 환경을 제공합니다.
*   **자동화된 인사이트 도출**: AI 분석을 통해 데이터의 주요 특징, 패턴, 이상치, 추세 등을 자동으로 분석하고, 실행 가능한 인사이트가 담긴 리포트를 생성합니다.
*   **분석 효율성 극대화**: '시각화 가이드' 기능을 통해 데이터 특성에 가장 적합한 분석 방법을 추천하여, 분석에 소요되는 시간과 노력을 최소화합니다.
*   **사용자 친화적인 경험**: 복잡한 분석 과정을 단순화하고, 모든 기능을 쉽게 접근하고 사용할 수 있는 인터랙티브 인터페이스를 제공합니다.

---

## 3. 타겟 사용자 (Target Audience)

*   **제조 현장 엔지니어**: 설비의 일상적인 모니터링, 이상 감지, 유지보수 계획 수립 등을 담당하는 기술자.
*   **데이터 분석가**: 현장 데이터를 기반으로 설비 성능 최적화, 예측 모델 개발 등을 수행하는 분석 전문가.
*   **공장 관리자 및 의사결정권자**: 데이터 분석 결과를 바탕으로 생산성 향상, 비용 절감 등 경영 관련 의사결정을 내리는 관리자.

---

## 4. 주요 기능 (Features)

### 4.1. 다차원 데이터 시각화
*   **기본 시각화**: 시계열 차트, 히스토그램, 박스플롯, 히트맵 등 표준적인 시각화 도구를 제공합니다.
*   **고급 분석 시각화**: 주파수 분석(FFT), 시간-주파수 분석(Wavelet), 상관관계 분석, 패턴 클러스터링 등 심층 분석을 위한 시각화 기능을 제공합니다.
*   **인터랙티브 차트**: 모든 차트는 확대/축소, 특정 구간 선택, 툴팁 정보 표시 등 동적인 상호작용이 가능합니다.

### 4.2. 인사이트 리포트
*   **자동 리포트 생성**: 클릭 한 번으로 현재 데이터에 대한 분석 리포트를 생성합니다.
*   **리포트 유형**:
    *   **종합 분석**: 데이터의 전반적인 통계, 분포, 추세, 이상치 등을 요약합니다.
    *   **이상치 분석**: 감지된 이상치에 대한 상세 정보와 발생 패턴을 심층 분석합니다.
    *   **패턴 분석**: 시간별, 요일별, 계절별 등 주기적인 데이터 패턴을 분석합니다.
    *   **성능 추세 분석**: 장기적인 데이터 추세를 분석하여 설비 성능 변화를 추적합니다.
*   **리포트 다운로드**: 생성된 리포트를 Markdown 형식으로 다운로드하여 보고서 작성에 활용할 수 있습니다.

### 4.3. AI 기반 분석 및 Q&A
*   **자동 분석 코멘트**: 각 시각화 차트에 대해 AI가 통계적 의미와 주요 특징을 텍스트로 자동 요약해줍니다.
*   **자연어 질문 및 답변 (Q&A)**: "가장 센서값이 높았던 때는 언제야?" 와 같이 자연어로 데이터에 대해 질문하면, AI가 분석하여 답변을 생성합니다.


### 4.4. 시각화 추천 가이드
*   **데이터 특성 자동 분석**: 로드된 데이터의 시계열 특성, 분포, 주기성 등을 자동으로 감지합니다.
*   **최적 분석 경로 추천**: 분석 목적(예: 이상치 찾기, 트렌드 보기)과 데이터 특성에 맞는 최적의 시각화 방법을 추천합니다.
*   **인터랙티브 흐름도**: 추천된 분석 단계를 시각적인 흐름도로 제공하며, 각 단계를 클릭하면 해당 시각화 화면으로 즉시 이동합니다.

### 4.5. 사용자 인터페이스 (UI)
*   **모듈화된 메뉴**: 모든 시각화 및 분석 기능은 사이드바에 체계적으로 정리되어 쉽게 접근할 수 있습니다.
*   **상태 유지**: 사용자가 선택한 데이터나 설정은 페이지를 이동해도 유지되어 분석의 연속성을 보장합니다.
*   **대용량 데이터 처리**: 수백만 건 이상의 대용량 데이터도 샘플링 옵션을 통해 메모리를 효율적으로 관리하며 안정적으로 시각화합니다.

## 5. 기술 요구사항 (Technical Requirements)

*   **프레임워크**: Streamlit
*   **언어**: Python
*   **주요 라이브러리**: Pandas, NumPy, SciPy, Plotly, Scikit-learn, Statsmodels, PyWavelets, CatBoost
*   **실행 환경**: 웹 브라우저 (Chrome, Firefox, Edge 등)

---

## 6. 성공 지표 (Success Metrics)

*   **사용자 만족도**: 정기적인 설문조사를 통해 사용자의 만족도 점수(CSAT) 측정.
*   **기능 사용률**: 종합 인사이트 리포트, AI Q&A 등 핵심 기능의 월간 활성 사용률(MAU) 추적.
*   **분석 시간 단축**: IoT Prism 도입 전후로 특정 분석(예: 이상 원인 파악)에 소요되는 평균 시간 비교.
*   **재사용률**: 한 번 사용한 유저가 다음 주, 다음 달에도 다시 방문하는 비율(Retention Rate) 측정.
